Recording opens the microphone unless audio is disabled on platforms that honour it. The plugin does not ask for the permission, so grant it first.

Readiness and lifecycle

  1. Background and resume. Start a preview, press Home, return to the app. The log should show readiness going to false, then back to true, with no new start().
  2. Rotation. Rotate the device with lockAndroidOrientation false and then true, and compare the preview with the outlined rectangle each time.
  3. Zoom and focus. With enableZoom true and the preview in front of the page, pinch inside it and tap to focus. Take a sample before and after to compare magnification.

Permissions

  1. Deny the camera prompt once: start() should reject with a permission message, and the app should stay usable.
  2. Deny it twice: the prompt stops appearing. Re-enable the permission in the system settings (or adb shell pm revoke / pm grant), then press Start again without relaunching.
  3. The same applies to the microphone for recording.
